# 小镇地图结构

运行时地图 `frontend/src/tiled/nature-open-world.tmx` 由
`frontend/scripts/build-nature-map.mjs` 确定性生成。地图尺寸保持 **64×48**，
出生点、五个地标及挂机巡游坐标均沿用 v1。

## 图层与碰撞约定

图层按 `Ground → Terrain → Buildings → Facade → Nature → Objects` 排列。

- `Ground`：草地底色及少量色差。
- `Terrain`：水边界、道路、广场石板及泥土斑。
- `Buildings`：隐藏的完整建筑 footprint 碰撞层。屋顶、墙体所在的每一格都
  阻挡，因此不能从北侧走上屋顶。
- `Facade`：只承载房屋外观，不承担碰撞；门前一格及道路仍可通行。
- `Nature`：边缘树木、石块与花草，避开房屋正面和入口。
- `Objects`：出生点及五个原位置招牌。

## 房屋瓦片矩阵

矩阵中的编号为 `[Base]BaseChip_pipo` 全局 tile ID；每栋立面前两行为屋顶，
后三行为墙体。门由上、下两格组成。

- **A（木屋）**：组合屋顶 `336–338 / 344–346`，木墙 `352–354`，门
  `375 / 383`。
- **B（浅色墙）**：组合屋顶 `339–341 / 347–349`，浅墙 `416–418`，拱门
  `391 / 399`。
- **C（带窗木屋）**：采用 A 的屋顶和墙体，正面嵌入三格宽窗组件
  `368–370 / 376–378`。

五栋建筑分别使用 A、B、C、B、A，集市保留 6×5，其余为 5×5。具体逐格
矩阵由脚本中的 `styleA`、`styleB`、`styleC` 生成，避免手工修改 TMX 后漂移。

## 地面变化

中央广场使用区别于道路的石板 tile；道路仍保持连续。草地散布轻微底色、
花草和小块泥斑，所有变化均使用固定坐标，构建可复现且不占用入口。
